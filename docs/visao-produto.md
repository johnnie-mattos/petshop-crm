# Visão do Produto

O sistema será utilizado por mim (funcionário) e pelos proprietários do pet shop. Sua função principal é:

- Manter o cadastro de clientes (e de seus pets);
- Identificar quais produtos cada cliente costuma comprar;
- Apoiar o contato com o cliente, usando como critério o tempo desde a última compra ou promoções relevantes para o perfil dele.

## Fora do escopo (por enquanto)

O sistema **não** trata compras, estoque, notas fiscais ou caixa. Todo esse processo permanece sob responsabilidade do sistema Open (PDV/ERP já utilizado pela loja) — o CRM apenas referencia essas informações quando necessário, sem duplicar esse controle.

## Evolução prevista

Conforme o projeto avançar, serão incorporados:
- Um planner (organização de tarefas/agenda);
- Ferramentas de análise de dados (relatórios, dashboards).
