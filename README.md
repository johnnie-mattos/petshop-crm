# Petshop CRM

Sistema de CRM para gestão de relacionamento com clientes de um pet shop, desenvolvido como projeto de portfólio e de uso real no negócio.

## Contexto

O sistema referencia o sistema de vendas (PDV/ERP) já existente na loja, sem duplicar controle de estoque, caixa ou notas fiscais. Seu foco é: cadastro de clientes e de seus pets, histórico de compras (por referência), promoções e o fluxo de contato/relacionamento com o cliente.
